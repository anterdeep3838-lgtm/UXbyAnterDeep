# KwicK prototype

Home-services booking app for India. React 19 + Radix UI + Tailwind, bundled to plain JavaScript.

## Run
- Windows: double-click `start-windows.bat`, then open http://localhost:8102/
- Mac/Linux: `./start-mac-linux.sh`, then open http://localhost:8102/
- `index.html` = desktop view (phone column on teal gradient). `app.html` = the app full screen.

## Folders
```
kwick-prototype/
├── app/                      <- the runnable site (serve this folder)
│   ├── index.html            desktop frame + background
│   ├── app.html              the app page (loads app.css + app.js)
│   ├── app.css               all styles (Tailwind output + KwicK styles)
│   ├── app.js                the app, GENERATED by build.py from src/
│   ├── fonts/                Figtree (self-hosted, OFL licence)
│   ├── motion/               layered images for the animated onboarding/tracking scenes
│   ├── technicians/          technician portraits
│   └── *.png / *.webp        characters, icons, illustrations
├── src/                      <- edit here
│   ├── app/                  KwicK's own code, one file per module:
│   │     011__app_page.tsx.js          all screens and flows (auth, questions, booking, tracking...)
│   │     160__app_home-screen.tsx.js   Home screen
│   │     156__app_kwick-data.ts.js     services, technicians, prices, copy
│   │     157__app_indian-locations.ts.js  city / area list
│   │     158__app_help-content.ts.js   Help centre text
│   │     159__app_motion.tsx.js        animated scene components
│   │     014/152/153/154__components_ui_*  button, sheet, tabs, toast
│   ├── vendor/               React, Radix, lucide icons etc. (do not edit)
│   ├── _prologue.js / _epilogue.js     tiny module loader
│   └── build-order.json      order the files are joined in
└── build.py                  joins src/ back into app/app.js
```

## Editing workflow
1. Change text, data or screens in `src/app/...` (for styling, edit `app/app.css` directly).
2. Run `python build.py` (Python 3, no packages).
3. Refresh the browser.

## About the source
The original TypeScript (.tsx) project is not in these files; the app was delivered as a bundle.
`src/app/` holds that same code as the TypeScript compiler output: same structure, names, text and logic,
just with types removed and JSX written as `jsx("div", {...})` calls. It is fully editable,
and `build.py` reproduces the shipped `app.js` byte for byte when nothing is changed.
Images are referenced by file name from the code, so keep file names when swapping images.

# KwicK: original source project

This folder is the original project the KwicK app was built from. It is a Next.js-style
app built with vinext and Vite, with the KwicK screens in `app/page.tsx` and data in
`app/kwick-data.ts`. The `.tsx` files are the originals.

The app folder `../app/` is the separately runnable prototype. This folder is the source to edit.

## Requirements
- Node.js 22.13.0 or newer (check with `node -v`)

## Install
```
npm run install:ci
```
This runs `npm ci` against the included `package-lock.json`. If it fails, `npm install` also works.

## Develop (hot reload)
```
npm run dev
```
Open http://localhost:5173/ . Use `npm run dev -- --port 5180` to pick another port.

## Production build
```
npm run build
```
Output goes to `dist/`, which is generated and not included here.

## Preview the production build locally
```
npm start
```
Runs the built app with Wrangler on 127.0.0.1. Use the URL printed in the terminal.

## Not included (regenerated by the commands above)
`node_modules/`, `.vinext/`, `.wrangler/`, `.sites-runtime/`, `dist/`, `.next/`

## Notes
- The sign-in helpers in `app/chatgpt-auth.ts` are for the hosted environment. The local dev
  mock sign-in is at `/signin-with-chatgpt?return_to=/` and is not part of production.
- Database files (`db/`, `drizzle/`) are optional for the KwicK screens.
- The project's own README is kept as `README.md` in this folder.
